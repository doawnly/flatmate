# FlatMate

A full-stack household expense and bill management application.

## Overview

FlatMate is a household management application designed to help
roommates track shared expenses, bills, and outstanding balances.

## Planned Features

- Household management
- Shared expense tracking
- Expense splitting
- Balance calculation
- Bill tracking
- Shopping lists
- Spending summaries

## Technology Stack

- Java
- Spring Boot
- PostgreSQL
- HTML/CSS/JavaScript
- Maven
- JUnit
- Git/GitHub
